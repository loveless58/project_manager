# 项目记录 · 标准模板

> 数据驱动版本（基于 28 个项目样本反向抽取的字段约定）
> 替换原 6 字段简化模板，让 `bid_deadline` 等高频但低填充字段有结构化位置。

---

## 使用说明

1. 新建项目时复制本模板到 `项目文件/{阶段}/{项目名}/项目记录.md`
2. 必填项（标 ✱）必须填，可选项可填 `—` 或留空
3. 截止日期格式：`YYYY-MM-DD` 或 `YYYY年MM月DD日`（两种都支持解析）
4. 金额格式：阿拉伯数字+元 / 中文万 / 带预算标签均可（见各示例）

## 备注

- 字段命名约定：`项目名称`（不是 `project_name`）/ `招标人/客户`（不是 `customer`）/ `负责销售`（不是 `sales_person`）等
- OCR 提取层字段（`buyer` / `seller` / `date` / `amount`）通过 `contracts/ocr_aliases.py` 映射到账本字段
- 项目记录.md 是 source of truth，index.json 仅作为元数据快照（不作为 deadline 等关键字段来源）
