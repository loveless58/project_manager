# 项目管理

## 定位

本 skill 面向本地项目目录和派生报告。它可以查看项目、检查风险、生成报告、迁移阶段和整理项目资料，但不直接执行 CloudCC/CRM 查询、招标公告解析或外部系统写入。

运行时工具事实来源是 `ToolRegistry`、`main.SKILL_TOOL_MAP` 和 `governance/project_schema.json`。本文只描述边界，不维护第二份完整工具表。

## 输入输出

输入可以是项目状态、风险、进度、交付物、报告或阶段迁移目标。输出可以是结构化检查结果、本地报告、总览页面或本地项目目录变更结果。

默认数据源是三阶段项目目录：

```text
项目文件/
  项目投标/
  项目执行/
  项目归档/
```

## 硬规则

- 找不到项目、目录不存在、文件不可读时必须返回结构化失败，不得推断为风险为零。
- 阶段迁移和文件整理必须限制在本地项目目录或显式传入路径。
- 本地报告和总览是派生产物，不代表 CRM、BPM 或合同系统已更新。
- 不绕过数据清洗及文件整理 skill 的项目账本证据规则。
- 涉及移动、迁移或覆盖时，上层流程必须保留确认边界。

## 软规则

优先先建立项目上下文，再做里程碑、交付物、风险或报告派生。跨系统状态缺失时，返回缺口和下一步动作，而不是补造事实。
