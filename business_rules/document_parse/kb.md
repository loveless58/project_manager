# Document Parse Knowledge Base — 业务规则库(L1)

> 文档解析分类规则,基于真实样本误分类反推扩种。
> **数据驱动**: 每条规则都来自真实样本验证,非预先设计。
> **优先级**: 文件名前缀 > 正文关键词(前缀更可靠,因为正文常含跨类别术语)

## 招标公告

**类别**: 招标公告(政府采购/企业采购发布的招标信息)

**触发信号**(任一):
- 关键词: 招标公告 / 采购公告 / 公开招标 / 邀请招标 / 招标说明书 / 招标文件
- 文件名前缀: 招标文件 / 竞价文件 / 招标公告 / 采购公告

**典型样本**:
- 项目投标/手持管理终端采购项目/招标文件/招标文件.docx ✓(839 段,12 表)

**易混类别**: 报名材料(招标文件里有报名表) / 合同文件(招标文件里提到合同条款) → 文件名前缀"招标"是最可靠信号

## 合同文件

**类别**: 合同文件(合同/协议/维保合同/技术开发合同)

**触发信号**(任一,**优先级最高**):
- 文件名前缀: 合同 / 协议 / 维保 / 法审 / 合作协议 / 技术开发合同 / 服务协议
- 正文复合条件: 含"合同" + 含("签订" / "签署" / "法审" / "生效" / "水印版")

**典型样本**:
- 20250527-核心网络设备维保维护服务合同2025.docx ✓
- 已法审-内蒙古农村商业银行股份有限公司呼和浩特中心支行2026-2027年度九楼机房X86等设备维保合同-622.docx ✓
- 中国烟草总公司山西省公司网络和安全设备、机房、软硬件平台运维服务项目合同（水印版）.docx ✓
- 服务器区防火墙系统升级采购合同.docx ✓
- 维保合同_文字版.docx ✓
- 技术开发合同-居家药学服务系统20260626.docx ✓

**易混类别**: 投标文件(合同文件可能含"投标响应""投标报价"等业务术语) → **关键**: 文件名前缀含"合同"是黄金信号,优先级 > 正文关键词

## 报名材料

**类别**: 报名材料(报名表/登记/承诺函/授权委托等参与资格材料)

**触发信号**(任一):
- 文件名前缀: 投标人信息登记备案表 / 报名表 / 承诺函 / 授权委托书 / 报名材料 / 报名所需资料 / 报名
- 关键词: 报名 / 报名表 / 登记 / 备案 / 承诺函 / 授权委托 / 资料

**典型样本**:
- 项目投标/七所报名项目/报名材料/投标人信息登记备案表.docx ✓
- 项目投标/紫金矿业入围项目/报名材料/廉洁合作承诺函.docx ✓
- 项目投标/紫金矿业入围项目/报名材料/供应商业务授权委托书模板.docx ✓
- 项目投标/任务与服务调度管理系统/报名材料/任务与服务调度管理系统-附件1 授权委托书等.docx ✓
- 项目投标/中国烟草总公司山西省公司2026-2029年网络和安全设备运维服务/报名材料/购买招标文件所需资料.docx ✓

**易混类别**: 合同文件(承诺函/授权委托可能含"合同"+"签订") → **关键**: 文件名前缀含"承诺函""授权委托""报名""登记"是黄金信号,优先级 > 正文关键词

## 其他

**类别**: 默认 fallback(没匹配上面任何类别 / 纯统计/明细/模板类)

**触发信号**(任一):
- 文件名前缀: 统计 / 明细 / 模板 / 列表 / 凭证 / 报备 / 预测 / 汇总 / 全订单 / 资金滚动 / 开票申请
- 无任何其他类别命中

**典型样本**:
- 项目文件/项目明细表.xlsx ✓
- 项目文件/投标项目分状态统计.xlsx ✓

**备注**: 表格类(.xlsx)常含跨类别关键词(如"投标项目分状态统计"),靠内容分类容易误判,**"统计"/"明细"等前缀是"其他"的黄金信号**(优先级与"合同"/"报名"等强信号同级)

---

## 优先级不变量(硬规则)

```
1. 文件名前缀(强信号): "合同"/"承诺函"/"授权委托"/"报名"/"登记"/"招标"/"竞价" > 一切正文
2. 正文复合条件(中等): 关键词 + 复合条件(如"合同"+"签订")
3. 单一关键词(弱信号): 仅当 1+2 都不命中
```

## LLM fallback 触发条件(MVP 2)

仅当:
- KB 匹配 confidence < medium
- **或** 多个类别命中且 KB 章节冲突

LLM prompt 模板:`system: "你是文档分类助手,基于 KB 章节规则判断"` + `user: "{raw_text[:2000]}"` + `tools: 5 类 enum`
